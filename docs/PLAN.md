# План работ

Цель: настольный органайзер с вкладками, куда задачи и заметки можно вводить с клавиатуры или голосом. Работает без интернета, а русскую речь с английскими названиями распознаёт правильно.

## Требования

- Вкладки сверху. Сначала одна вкладка, «Задачи». Можно добавить сколько угодно вкладок с любыми названиями, на экране видна одна.
- В вкладке лежат записи: задачи с галочками или просто заметки.
- Голосовой ввод работает офлайн, понимает русскую речь и пишет английские названия латиницей.
- Современный аккуратный дизайн, светлая и тёмная тема.
- Архитектура, которую можно расширять: новые типы вкладок, синхронизация, мобильная версия.
