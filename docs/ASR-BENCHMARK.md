# Выбор модели распознавания речи

**Итог:** Whisper Large v3 (whisper.cpp, видеокарта NVIDIA) с языком `ru`, подсказкой о стиле, словарём пользователя и VAD.
На тестовом наборе эта связка пишет **97 %** английских названий латиницей при **2,7 %** ошибок в словах. Одна фраза распознаётся примерно за **0,35 с** на RTX 3060 Laptop.

## Что сравнивали

Требование: распознавание без интернета, русская речь, в которую вставлены английские названия («залить проект на GitHub»). Названия должны писаться как есть, латиницей.

Кандидаты, которые реально запускаются офлайн на Windows через [whisper.cpp](https://github.com/ggml-org/whisper.cpp) v1.9.5:

| Модель | Размер | Почему в списке |
|---|---|---|
| Whisper Large v3 | 3,1 ГБ | лучшая многоязычная модель Whisper |
| Whisper Large v3 Turbo | 1,6 ГБ | вдвое быстрее, меньше слоёв декодера |
| NVIDIA Parakeet TDT 0.6B v3 | 1,3 ГБ | поддерживает русский, нет привязки к одному языку |

GigaAM v3 (Сбер) лучше всех понимает чисто русскую речь, но её алфавит состоит только из кириллицы. Английские слова она пишет русскими буквами, поэтому под требование не подходит.

## Набор данных

[`tools/asr-bench/sentences.json`](../tools/asr-bench/sentences.json): 33 фразы в стиле списка дел.

- 28 фраз с английскими названиями: Windows, Telegram, GitHub, Docker, Kubernetes, PostgreSQL, ChatGPT Plus и другими. В половине из них текст для синтеза записан кириллицей («гитхаб», «докер»), чтобы диктор произносил название по-русски, как обычный человек.
- 4 чисто русские фразы. Они проверяют, что подсказки не портят обычную речь.
- 1 длинная фраза с четырьмя названиями.

Каждую фразу озвучили два синтетических голоса (Microsoft Edge TTS): `ru-RU-SvetlanaNeural` (русский) и `en-US-AndrewMultilingualNeural` (говорит по-русски, а английские названия произносит как носитель языка). Всего 66 записей.

## Результаты

Метрики: **WER**, доля ошибок в словах по всем фразам (меньше — лучше); **термины**, доля английских названий, записанных латиницей и правильно (больше — лучше); **WER рус.**, ошибки только на чисто русских фразах.

| Конфигурация | WER | Термины | WER рус. | Время на фразу |
|---|---:|---:|---:|---:|
| Large v3, `ru`, без подсказки | 9,8 % | 68,1 % | 4,5 % | 347 мс |
| Large v3, `ru`, подсказка о стиле | 5,4 % | 87,5 % | 4,5 % | 343 мс |
| Large v3, `ru`, стиль + словарь | 2,7 % | 97,2 % | 6,8 % | 356 мс |
| **Large v3, `ru`, стиль + словарь + VAD** | **2,7 %** | **97,2 %** | **4,5 %** | **362 мс** |
| Large v3, автоопределение языка, стиль | 6,4 % | 87,5 % | 4,5 % | 518 мс |
| Large v3 Turbo, `ru`, без подсказки | 8,3 % | 73,6 % | 4,5 % | 189 мс |
| Large v3 Turbo, `ru`, стиль | 7,1 % | 83,3 % | 9,1 % | 190 мс |
| Large v3 Turbo, `ru`, стиль + словарь | 4,9 % | 90,3 % | 6,8 % | 195 мс |
| Parakeet TDT 0.6B v3 | 14,5 % | 55,6 % | 13,6 % | — |

Железо: AMD Ryzen 7 4800H, NVIDIA RTX 3060 Laptop (6 ГБ), CUDA 12.4. Модель Large v3 загружается в видеопамять примерно за 4 секунды.

**Подсказка о стиле.** Это одно предложение, которое показывает модели, что английские названия внутри русской речи пишутся латиницей: «Список дел: открыть Slack, проверить задачи в Jira, обновить Chrome и макет в Figma.» Названий из тестового набора в нём нет.

**Словарь.** Названия, которые пользователь добавил в словарь приложения, дописываются к подсказке («Термины: Docker, GitHub, …»). В тесте словарь содержал все названия из набора: так выглядит ситуация, когда пользователь уже занёс свои частые слова.

## Оставшиеся ошибки лучшей конфигурации

- Числа модель пишет цифрами: «в 3 часа» вместо «в три часа», «до 20 числа». Для списка дел это скорее плюс.
- «наушен» вместо «Notion»: диктор произнёс название слишком по-русски. Это исправит словарь замен: после первой ручной правки приложение предложит запомнить «наушен» → «Notion».
- Пара ошибок в обычных словах у второго диктора с английским акцентом («качать пастырю версию»).

## Что из этого сделано в приложении

1. Модель по умолчанию — Whisper Large v3, язык `ru`. Автоопределение языка хуже и медленнее.
2. Подсказка о стиле включена всегда, к ней дописываются слова из словаря ([`src/shared/text/prompt.ts`](../src/shared/text/prompt.ts)).
3. Включён VAD (Silero): он отрезает тишину, и модель не придумывает текст на паузах.
4. После распознавания применяется словарь замен с учётом русских окончаний: «докера» → «Docker» ([`src/shared/text/replacements.ts`](../src/shared/text/replacements.ts)).
5. Если пользователь исправил распознанный текст, приложение предлагает запомнить исправление ([`src/shared/text/learn.ts`](../src/shared/text/learn.ts)).
6. Turbo и сжатые версии доступны в настройках для компьютеров без мощной видеокарты.

## Как повторить

```bash
# 1. Озвучить фразы (нужен интернет и пакет edge-tts)
python -m venv .venv && .venv/Scripts/pip install edge-tts
.venv/Scripts/python -I tools/asr-bench/gen_tts.py tools/asr-bench/sentences.json bench/audio

# 2. Прогнать модели через whisper-server (папка с whisper.cpp, папка с моделями, папка с audio/ и sentences.json)
node tools/asr-bench/run_bench.mjs <whisper-bin-dir> <models-dir> <bench-dir> <bench-dir>/results.json
```

Полные ответы моделей лежат в [`tools/asr-bench/results.json`](../tools/asr-bench/results.json).

**Ограничения теста.** Речь синтетическая, а живой голос, микрофон ноутбука и шум дадут больше ошибок. Абсолютные цифры будут хуже, но порядок конфигураций должен сохраниться: разница между ними большая.
