# Органайзер задач

Приложение для Android: вкладки со списками задач и заметками, которые можно надиктовать голосом. Речь распознаёт встроенная служба телефона — та же, что у голосового ввода на клавиатуре.

## Возможности

- Вкладки сверху. Сначала одна, «Задачи». Добавлять можно сколько угодно, с любыми названиями, цветом и типом: задачи с галочками или заметки.
- Записи: добавить, изменить, перетащить, перенести в другую вкладку.
  - Действия с записью — кнопка «⋮»: важность, изменить, срок, перенос, удаление. Нажатие и удержание на самой записи ничего не делают, нажатие на пустое место убирает курсор.
  - Свайп вправо — выполнено, свайп влево — удалить, с отменой.
- Важность: серый (обычная), жёлтый, красный (самая важная). По умолчанию сверху красные, потом жёлтые, потом серые: отмеченная запись сразу переезжает наверх. В настройках можно сортировать по дате добавления.
- Срок: дата и, по желанию, время.
- Напоминания в уведомлениях. В настройках:
  - за сколько напоминать, можно несколько раз и свои интервалы;
  - повторы после срока, пока задача не выполнена;
  - на сколько откладывать;
  - во сколько напоминать о задачах без времени;
  - для каких уровней;
  - пропущенные напоминания после включения телефона;
  - режим будильника;
  - отдельные звук и вибрация для каждого уровня.
- Голосовой ввод через системный распознаватель Android. Можно выбрать службу распознавания (Google, Samsung и другие), язык и режим «только без интернета».
- Словарь. Английские названия, которые распознавание пишет по-русски, заменяются с учётом падежей: «докера» → «Docker».
- Оформление: 8 стилей — Стандарт, Минимализм, Мягкий, Строгий, Терминал, Блокнот, Компактный, Неон. У каждого свой шрифт, набор значков, форма кнопок, переключателей и полей, вид записей, вкладок, микрофона, флажков важности и фона. К ним 10 цветов, включая цвета из обоев, светлая, тёмная и чёрная темы.
- Шрифты Manrope, Nunito, Oswald, Roboto Condensed, JetBrains Mono, Caveat и Exo 2 встроены в приложение (SIL Open Font License, тексты лицензий в `app/src/main/assets/licenses`).
- Поиск по всем вкладкам, корзина на 30 дней, ежедневные резервные копии, экспорт и импорт в JSON.

## Установка

Скачайте `TaskOrganizer-*.apk` со страницы [Releases](https://github.com/Keavors/TaskOrginizer/releases), откройте на телефоне и разрешите установку из этого источника.

## Сборка

Нужны JDK 21 и Android SDK (платформа 37).

```bash
./gradlew testDebugUnitTest   # юнит-тесты логики
./gradlew assembleRelease     # app/build/outputs/apk/release/app-release.apk
./gradlew installRelease      # сразу на подключённый телефон (отладка по USB)
```
