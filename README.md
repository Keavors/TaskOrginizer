# Органайзер задач

Приложение для Android: вкладки со списками задач и заметками, которые можно надиктовать голосом. Распознавание речи работает прямо на телефоне, без интернета, и пишет английские названия внутри русской речи латиницей: «залить проект на GitHub», а не «на гитхаб».

## Возможности

- Вкладки сверху. Сначала одна, «Задачи». Добавлять можно сколько угодно, с любыми названиями, цветом и типом: задачи с галочками или заметки.
- Записи: добавить, изменить, отметить важной, срок, перетащить, перенести в другую вкладку.
  - Свайп вправо — выполнено.
  - Свайп влево — удалить, с отменой.
- Голосовой ввод на модели Whisper Large-v3-Turbo (whisper.cpp) с подсказками для модели, словарём и VAD:
  - короткое нажатие на микрофон — говорить до следующего нажатия;
  - удержание — режим рации.
- Словарь. Слова из него модель ждёт услышать, а типичные ошибки («докера» → «Docker») исправляются с учётом падежей. Если поправить надиктованное слово вручную, приложение предложит запомнить исправление.
- Поиск по всем вкладкам, корзина на 30 дней, ежедневные резервные копии, экспорт и импорт в JSON.
- Светлая и тёмная тема, по желанию цвета из обоев (Material You).

## Установка

1. Соберите APK (см. ниже) или возьмите готовый `app-release.apk`.
2. Скопируйте его на телефон и откройте. Если Android спросит, разрешите установку из этого источника.
3. При первом запуске нажмите «Скачать» в баннере голосового ввода. Модель весит 874 МБ, качать её лучше по Wi‑Fi. Это нужно один раз, дальше всё работает без интернета.

## Сборка

Нужны JDK 21, Android SDK (платформа 37, NDK 29.0.14206865, CMake 3.31.6).

```bash
./gradlew testDebugUnitTest   # юнит-тесты логики
./gradlew assembleRelease     # app/build/outputs/apk/release/app-release.apk
./gradlew installRelease      # сразу на подключённый телефон (отладка по USB)
```

whisper.cpp v1.9.5 скачивается при сборке с проверкой SHA-256 и всегда собирается с оптимизацией (`-O3`), даже в отладочной сборке.
