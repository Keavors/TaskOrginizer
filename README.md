# Органайзер задач

Приложение для Android: вкладки со списками задач и заметками, которые можно надиктовать голосом. Речь распознаёт встроенная служба телефона — та же, что у голосового ввода на клавиатуре. Текст появляется прямо во время речи; без интернета распознавание работает, если у службы скачан язык.

## Возможности

- Вкладки сверху. Сначала одна, «Задачи». Добавлять можно сколько угодно, с любыми названиями, цветом и типом: задачи с галочками или заметки.
- Записи: добавить, изменить, отметить важной, срок, перетащить, перенести в другую вкладку.
  - Свайп вправо — выполнено.
  - Свайп влево — удалить, с отменой.
- Голосовой ввод через системный распознаватель Android:
  - короткое нажатие на микрофон — слушает, пока вы говорите, или до следующего нажатия;
  - удержание — режим рации;
  - в настройках: служба распознавания (Google, Samsung и другие), язык, «Только без интернета».
- Словарь. Английские названия, которые распознавание пишет по-русски, заменяются с учётом падежей: «докера» → «Docker». Если поправить надиктованное слово вручную, приложение предложит запомнить исправление. На Android 13+ слова из словаря ещё и передаются распознавателю как подсказки.
- Поиск по всем вкладкам, корзина на 30 дней, ежедневные резервные копии, экспорт и импорт в JSON.
- Светлая и тёмная тема, по желанию цвета из обоев (Material You).

## Установка

1. Соберите APK (см. ниже) или возьмите готовый `app-release.apk`.
2. Скопируйте его на телефон и откройте. Если Android спросит, разрешите установку из этого источника.
3. Для работы без интернета у выбранной службы распознавания должен быть скачан язык.

## Сборка

Нужны JDK 21 и Android SDK (платформа 37).

```bash
./gradlew testDebugUnitTest   # юнит-тесты логики
./gradlew assembleRelease     # app/build/outputs/apk/release/app-release.apk
./gradlew installRelease      # сразу на подключённый телефон (отладка по USB)
```
